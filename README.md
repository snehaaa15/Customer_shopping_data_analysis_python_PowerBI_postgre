## Customer Shopping Behavior Analysis

## Overview 

Customer Shopping Behavior Analysis is a data analytics project designed to understand customer purchasing patterns, product preferences, revenue trends, and customer demographics. The project combines Python, PostgreSQL, SQL, and Power BI to transform raw shopping data into actionable business insights.

The goal of this project is to help businesses make data-driven decisions regarding customer segmentation, marketing strategies, product performance, and sales optimization.

---

## Project Objectives

* Analyze customer demographics and purchasing behavior.
* Identify revenue contribution by different customer groups.
* Examine the impact of subscriptions and discounts on purchases.
* Discover top-performing products and categories.
* Perform customer segmentation based on purchase history.
* Build an interactive Power BI dashboard for business insights.

## Dataset Information

The dataset contains customer shopping transactions with attributes such as:

* Customer ID
* Age
* Gender
* Item Purchased
* Product Category
* Purchase Amount
* Location
* Subscription Status
* Shipping Type
* Review Rating
* Previous Purchases
* Payment Method
* Purchase Frequency

---

## Data Preprocessing

Data cleaning and preprocessing were performed using Python.

### Steps Performed

* Loaded the dataset using Pandas.
* Checked data types and column information.
* Handled inconsistencies and redundant columns.
* Created derived features such as:

  * Age Group
  * Purchase Frequency Days
* Validated dataset quality before analysis.
* Exported the cleaned dataset for SQL and Power BI analysis.

---

## Database Analysis

The cleaned dataset was imported into PostgreSQL.

Several SQL queries were performed to answer business questions, including:

### Revenue Analysis

* Revenue by Gender
* Revenue by Category

### Customer Behavior Analysis

* Subscription vs Non-Subscription Customers
* Discount Usage Analysis

### Product Analysis

* Top Rated Products
* Category Performance

### Customer Segmentation

* New Customers
* Returning Customers
* Loyal Customers

---

## Power BI Dashboard

An interactive Power BI dashboard was created using the processed CSV dataset generated from Python.

### Dashboard Features

* Total Revenue KPI
* Total Customers KPI
* Average Review Rating KPI
* Revenue by Category
* Revenue by Gender
* Subscription Status Distribution
* Customer Age Group Analysis
* Product Performance Analysis
* Interactive Filters and Slicers

---

## Key Insights

* Certain product categories generated significantly higher revenue.
* Loyal customers contributed a large portion of overall sales.
* Subscription customers showed higher purchasing activity.
* Highly rated products demonstrated strong customer demand.
* Discounts positively influenced customer purchasing behavior.

---

## Challenges Faced

* PostgreSQL integration with Power BI Service on macOS required gateway configuration.
* Due to connectivity limitations, the final Power BI dashboard was built using the processed CSV dataset generated from Python.
* SQL analysis was performed separately in PostgreSQL.
